# Installing aMule from binaries

This fork supports Linux, macOS, FreeBSD, OpenBSD, and NetBSD. It does not
provide the upstream project's binary packaging; upstream releases and
distribution packages may contain a different version of aMule.

## Homebrew

On macOS or Linux, install this fork with the formula in the
[tgragnato/homebrew-tap](https://github.com/tgragnato/homebrew-tap):

```sh
brew install tgragnato/tap/amule
```

Alternatively, follow [INSTALL.md](INSTALL.md) to build and install from
source. After installation, see the [user guide](README.md) for configuration
and the [amuleapi quick start](QUICKSTART-AMULEAPI.md) for the REST API.
